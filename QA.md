# TEREN — финальный аудит

Дата: 29 сентября 2026. Проверялась локальная production-сборка Astro в Microsoft Edge (Chromium) через Playwright.

## Результаты

- `npm install`: успешно, lockfile сохранён.
- `npm run build`: успешно, 9 статических страниц.
- `npm run typecheck`: 0 ошибок, 0 предупреждений, 0 подсказок.
- `npm run lint`: успешно, 0 предупреждений.
- `npm test`: 7 сценариев успешно.

## Responsive и визуальная проверка

Все 9 страниц проверены при ширинах **320, 360, 390, 768, 1024, 1440, 1920 px** — 63 сочетания страницы и ширины, без горизонтального переполнения. Для каждой страницы сохранены полные скриншоты 390 и 1440 px. Просмотрены главная, индекс, три кейса, услуги, студия, контакты и 404. Отдельно оценены первый экран, типографика, фото, сетка, ритм секций и мобильная форма.

## Функциональность

- Проверены внутренние адреса, последовательный переход между проектами и возврат к каталогу.
- Неизвестный адрес возвращает HTTP 404 и фирменную страницу. Прямой запрос самой страницы 404 в preview может отвечать 200 — проверка ошибки выполняется на несуществующем URL.
- Mobile dialog: открытие с клавиатуры, удержание фокуса, Escape, возврат фокуса, закрытие при расширении viewport и переход по ссылке.
- Формы: обязательные поля, email, минимальная длина, checkbox, локальный результат и фокус на нём. Ни навигации, ни передачи формы, ни записи в storage/cookies.
- Услуги: раскрытие и закрытие details с клавиатуры.
- Sticky-индекс: корректная смена активной строки при прокрутке.
- Reduced motion: анимации отключены, контент доступен.
- Без JavaScript: контент и обычные ссылки работают, есть мобильная альтернативная навигация; форма выключена и объясняет причину.
- JavaScript page errors в основном проходе не обнаружены.

## Accessibility

Проверены semantic landmarks, один H1, labels, alt у всех изображений, aria-current, видимый focus, dialog, статус формы и reduced motion. Декоративные номера в меню скрыты от скринридера. Изображения в фоне текста дополнены затемнением. Контраст базового текста и акцентных элементов проверен расчётом; второстепенный текст и placeholder затемнены после аудита. Это целевая проверка, не независимая сертификация WCAG.

## Performance и SEO

- Статическая выдача без клиентского фреймворка.
- WebP: мобильные варианты примерно 54–67 KiB; 1280 px — 179–247 KiB; 1920 px — 285–416 KiB.
- responsive srcset/sizes, размеры изображений, lazy loading ниже первого экрана и высокий приоритет hero.
- Golos Text размещён локально; font-display: swap, Unicode subsets.
- CSS около 28 KiB до транспортного сжатия. Небольшой общий скрипт встроен сборщиком.
- Анимации ограничены transform/opacity и входным clip-path; scroll-driven эффекты имеют видимый статичный fallback.
- Все изображения успешно декодируются. Нет внешних запросов за шрифтами или изображениями.
- Уникальные title, description, H1 и корректные canonical/OG; robots noindex/nofollow и Disallow.
- Нет ложных сведений о реальном бизнесе или LocalBusiness schema.

## Исправления после первого прохода

1. На 320 px длинное название этапа расширяло двухколоночную сетку. Для экранов до 400 px создана компактная последовательность с отдельной колонкой номера.
2. Улучшен контраст второстепенного текста, placeholder и границ полей; добавлена контрастная подложка подписи на hero.
3. Добавлена полноценная мобильная навигация без JavaScript.
4. Декоративные номера меню исключены из доступных имён.
5. Приведены к единой вымышленной южной географии данные проектов и изображения.
6. Проверки изолированы от служебной dev-панели; итоговый прогон выполнен на production-сборке. Исправлены типы DOM в тестах и ожидание прямого URL 404.

## Реальные ограничения

- Проекты и схемы концептуальные; схема не заменяет рабочий чертёж. Три основные AI-визуализации переиспользуются и кадрируются в редакционных блоках.
- Форма намеренно не подключена к почте/CRM. Все контакты — placeholders.
- Автоматические проверки выполнены в Edge/Chromium; Safari, Firefox, физические iOS/Android и скринридеры отдельно не тестировались.
- Нативные View Transitions и scroll-driven animation зависят от поддержки браузера. Fallback сохраняет контент и навигацию.
- Нет полевых Core Web Vitals или подтверждённых Lighthouse-баллов. Размеры и стратегия загрузки проверены, скорость у реальных посетителей не измерена.
- Публикация Sites по умолчанию приватная; публичный доступ не включается автоматически.
