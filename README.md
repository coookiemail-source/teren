# TEREN

Портфолийная концепция независимой архитектурной студии. Все проекты, локации и контактные данные вымышлены; изображения созданы с помощью ИИ. Форма ничего не отправляет и не сохраняет.

## Запуск

Требуется Node.js 22.12+ (проверено на 24.16) и npm.

```sh
npm install
npm run dev
```

```sh
npm run typecheck
npm run lint
npm run build
npm run preview
```

## Страницы

- `/` — главная, scroll index, принципы, услуги, процесс.
- `/projects/` — редакционный индекс трёх проектов.
- `/projects/residence-01/` — подробный кейс дома.
- `/projects/quiet-interior/` — интерьерный кейс.
- `/projects/water-pavilion/` — общественный павильон.
- `/services/` — пять направлений с раскрывающимся составом работы.
- `/studio/` — философия и методология, честное описание концепции.
- `/contact/` — локальная демонстрационная форма.
- `/404.html` — страница ошибки; неизвестные адреса получают HTTP 404.

## Визуальная система

TEREN отсылает к земле и месту. Знак — два смещённых прямых угла: граница и открытое пространство между ними. Работает в header, favicon, финальном CTA, 404 и переходах между страницами.

Тёплый каменный фон, графит, киноварь. Локально размещённый вариативный Golos Text с кириллицей. Асимметричная сетка, крупная типографика, прямые углы, выразительные интервалы.

## Motion

- Hero: короткое появление текста, clip-path изображения и мягкое масштабирование.
- Sticky-индекс выбранных проектов; IntersectionObserver меняет активную строку.
- CSS scroll-driven reveal и параллакс в поддерживающих браузерах; при отсутствии поддержки контент остаётся видимым.
- Hover-масштабирование изображений и явные ссылки для touch.
- Анимированное нативное dialog-меню, focus trap, Escape и возврат фокуса.
- Нативные межстраничные View Transitions, отдельный переход знака.
- `prefers-reduced-motion` отключает анимации и плавную прокрутку.
- Нативная прокрутка без GSAP, Lenis, перехвата колеса или загрузочного экрана.

## Структура

`src/data/projects.ts` содержит проекты и услуги. Общий каркас, метаданные, header и footer — `src/layouts/Layout.astro`. Повторно используемые компоненты находятся в `src/components/`. Стили — `src/styles/`, небольшой интерактив — `src/scripts/main.ts`. Нет React, внешних API, аналитики и cookies со стороны сайта.

`public/images/` содержит локальные WebP в трёх разрешениях (640/1280/1920). `Picture.astro` задаёт srcset, sizes, размеры, loading и приоритет. Для замены изображений сохраните имена и соотношение 3:2 либо обновите компонент. Некоторые виды в кейсах — кадрирование одной визуализации, а не дополнительные ракурсы.

## SEO и публикация

У каждой страницы отдельные title, description, H1, canonical и Open Graph. Намеренно установлены `noindex, nofollow` и `robots.txt: Disallow: /`. Нет ложной LocalBusiness schema. Сайт зарегистрирован в Sites; его идентификатор находится в `.openai/hosting.json`, статический результат — `dist/`.

Для другого домена задайте `SITE_URL` перед сборкой. Концепция не проходила проверку товарного знака и не является рабочей архитектурной документацией.

## Тестирование

Smoke suite использует установленный Microsoft Edge:

```powershell
# В одном окне:
npm run preview -- --port 4323
# В другом:
$env:QA_BASE_URL='http://127.0.0.1:4323'
npm test
```

При необходимости задайте `QA_BROWSER_CHANNEL=chrome` или измените channel в `playwright.config.ts`. Браузер должен быть установлен. Скриншоты сохраняются в `.qa/`, результаты — в `test-results/`; оба каталога исключены из Git.

Подробные результаты и ограничения — в `QA.md`.
